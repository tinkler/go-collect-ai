# 品类补货周期表(2026-Q3)

> **作用**:LLM 在算"补多少"时,`lead_days` 按这张表取默认值。
>
> **可改**:老板 / 采购经理根据本地实际情况调。

## 一级品类

| 品类 | 默认 lead_days | 备注 |
|---|---|---|
| 食品(常温) | 7 | 大多数常温品(饮料/零食/调味料) |
| 食品(冷链) | 3 | 鲜奶/酸奶/速冻,周转快 |
| 食品(临期敏感) | 5 | 面包/熟食,临期风险高 |
| 饮料 | 7 | 瓶装水/茶饮,lead 不长 |
| 啤酒 | 7 | 夏季旺销,lead 不变 |
| 酒水(高端) | 14 | 白酒/洋酒,周转慢 |
| 日化(快消) | 14 | 洗发水/沐浴露/牙膏 |
| 日化(纸品) | 21 | 卷纸/抽纸/湿巾,体积大,补货周期长 |
| 烟 | 30 | 烟草,政策限制多,一次多备 |
| 母婴 | 14 | 奶粉/纸尿裤 |
| 文具/办公 | 30 | 开学季外很少动销 |
| 季节性(雪糕) | 3 | 节前 3 天补一次,节后停 |
| 季节性(月饼) | 3 | 中秋前 45 天密集补 |
| 季节性(火锅料) | 7 | 冬季旺销 |

## 二级品类微调

老板可以加二级品类,比如:
- "饮料-茶饮" → 5 天(比瓶装水周转快)
- "日化-宠物粮" → 21 天(宠物粮体积大)
- "食品-米面油" → 14 天(米面油体积大,补货慢)

## 季节性补货规则

| 阶段 | lead_days | 补货倍数 |
|---|---|---|
| 节前 > 30 天 | 默认值 | 1.0x |
| 节前 30-15 天 | 默认值 × 0.8 | 1.5x |
| 节前 15-7 天 | 默认值 × 0.5 | 3.0x |
| 节前 < 7 天 | 默认值 × 0.3 | 5.0x |
| 节后 | 默认值 | 0.0x(停止补货) |

> **注意**:以上"节" 包含 `seasonal-buying` skill 里的节假日表。LLM 看到 SKU 命中季节性 + 当前日期接近节前,自动套用本表。

## 编辑权限

老板和采购经理可加品类 / 调 lead_days / 调倍数。改完即生效。
