# 账期与 Buffer 选择指南

> **作用**:LLM 在 `suggest_supplier_payment` 调 `period_days` 和 `buffer_factor` 时参考。
> 默认值 `period_days=30` / `buffer_factor=1.5`,但**有些场景要调**。

## 账期(period_days / payment_cycle_days)

| 账期 | 适用场景 | 风险 |
|---|---|---|
| 7 天 | 生鲜/冷链/临期品(资金快进快出) | 高频对账,人力成本 |
| 15 天 | 季节性强、库存周转快 | 中等 |
| 30 天(**默认**) | 大多数常温品 | 行业标准 |
| 60 天 | 大型品牌、议价能力强 | 占用供应商现金流,关系风险 |
| 90 天 | 战略合作 / 独家 | 同上,且易被反向"卡脖子" |

## buffer_factor(安全垫)

| 系数 | 含义 | 适用 |
|---|---|---|
| 1.0 | 精准 | 不推荐 — 任何波动都会断货 |
| 1.2 | 紧 | 高确定性数据(cube 真实数据) |
| 1.5(**默认**) | 适中 | 大多数场景 |
| 2.0 | 宽 | 季节性 + 销量波动大 |
| 2.5+ | 极宽 | 节日 / 大促备货 |

## 编辑权限

老板和采购经理可改默认值(比如改成 1.3)。改完即生效。
