# 场景调整表(覆盖默认系数)

> **作用**:老板提到"战略供应商 / 新品推广 / 清仓"等场景时,LLM 套用本表覆盖默认系数。
>
> **优先级**:`老板的具体话 > 本表 > 默认系数`
>
> **示例**:老板说"汇一是战略供应商,调高到 1.4" → 直接用 1.4,不再看本表。

## 场景:战略供应商(Strategic)

**识别词**: "战略" / "核心" / "重点" / "独家" / "long-term partner"

**调整**:
- `investment_weight`: +0.2(默认 1.0 → 1.2)
- `sellthrough_weight`: 不变(战略不等于卖得快)

**适用**:
- 供应商份额 > 品类 30%
- 不可替代(品类里没有同档替代)
- 老板明确点名

## 场景:新品推广(NPI)

**识别词**: "新品" / "首发" / "刚上市" / "推广期" / "试销"

**调整**:
- `investment_weight`: 不变(供应商没多投)
- `promo_weight`: +0.1(支持终端动销)
- `sellthrough_weight`: -0.1(新品动销天然低,建议金额应该少)

**适用**:
- 上架 < 90 天
- 销量 < 品类的 20%(还没起来)

## 场景:清仓(Closeout)

**识别词**: "清仓" / "甩卖" / "退市" / "last batch" / "清货"

**调整**:
- `investment_weight`: -0.1(减少投入)
- `promo_weight`: +0.2(加大促销)
- `sellthrough_weight`: -0.2(预期压货卖不动)

**适用**:
- 临期 < 30 天
- 即将退市(供应商通知 / 合同到期)
- 库存 > 月销 × 3

## 场景:季节性(Seasonal)

**识别词**: "雪糕季" / "月饼季" / "火锅季" / "年货"

**调整**:
- 套用 `seasonal-buying` skill 给的 `recommended_multiplier` × `base_forecast` 作为 base,**不再用**默认日均
- `investment_weight`: 不变

**适用**:
- 距"季节开始" < 30 天
- 商品属于该季节核心品类

## 场景:反回扣高风险(Anti-Kickback)

**识别词**: "回扣" / "好处费" / "灰色" / "奇怪" / "突然换供应商"

**调整**:
- `investment_weight`: 不变
- **额外**: 立即套用 `supplier-policy` skill,查 `block_entry` / `block_reason` 字段
- 询问老板是否要**降级**到 0.7(降低建议金额,倒逼老板重新议价)

**适用**:
- 老板主动提到"防回扣"
- 系统检测到同一 SKU 多供应商报价差 > 30%

## 编辑权限

老板 / 采购经理 / 财务可以加新场景(比如"节日档"、"新品上架")。改完即生效。
