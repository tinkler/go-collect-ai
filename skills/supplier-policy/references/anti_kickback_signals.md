# 反回扣危险信号清单(2026-Q3)

> **作用**:LLM 录入 / 查询供应商政策时,自检本清单。命中"红信号"必须立即告诉老板。
>
> **原则**:宁可多问,不可漏报。

## 🔴 红色信号(立即警告老板)

| 信号 | 检测方式 | 老板话术参考 |
|---|---|---|
| **同 SKU 多供应商报价差 > 30%** | 调 `query_supplier_policy` + 商品库对比 | "XX 报价 5,YY 报 7,这价差很大,需要查一下" |
| **临时涨价 > 30%(无合同依据)** | 历史采购价对比 | "这周涨 30%,有合同/通知吗?" |
| **老板主动提"返点"/"回扣"** | 语义识别 | **直接拒绝**:"这个我不能记,建议走合同" |
| **新供应商无样品 / 无合同** | 老板话术识别 | "要不要先小批量试一下?" |
| **堆头费 > 月供 20%** | `promotion_fee` 数据 | "这堆头费比例很高,比惯例多 X%" |
| **老板问"私下转账给供应商"** | 语义识别 | **拒绝**,提示合规风险 |
| **临时换供应商 + 报价偏高** | 组合信号 | "换供应商了?价格对比一下" |

## 🟡 黄色信号(询问 + 记入 note)

| 信号 | 检测方式 | 建议动作 |
|---|---|---|
| 老板拒绝透露供应商身份 | 语义识别 | 问"哪家供应商",不深究,记入 note |
| 同一品类供应商数 < 2 | HHI 计算 | 建议老板"找备选供应商" |
| 老板多次说"换个供应商" | 历史 query 频次 | 建议保留"试用供应商"policy |
| 供应商承诺"独家给最低价" | 语义识别 | 问"有没有其他供应商比过价" |
| 老板话里有"关系户" / "老朋友" | 语义识别 | 提示"建议有书面合同" |
| 月度结算金额突然翻倍 | `settlement-suggestion` 数据 | 问"为什么涨这么多" |

## 🟢 绿色信号(正常)

- 老板按"质量 / 价格 / 账期"明确选供应商
- 老板要求多供应商比价
- 老板定期轮换供应商
- 老板主动记入 note 解释决策原因

## LLM 行动模板

### 命中红色信号

```
⚠️ 反回扣自检命中 [信号名]:
- 详情: ...
- 建议: ...
- 是否需要我帮你 [查历史价格 / 找备选供应商 / 加 block_entry] ?
```

### 命中黄色信号

```
提示: 注意到 [信号名],已经记入 [供应商] 的 note 字段。
```

## 编辑权限

老板和审计员可加新信号。改完即生效。
