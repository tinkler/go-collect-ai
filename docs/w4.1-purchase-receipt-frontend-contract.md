## 一、行为总览

### 1.1 重复图去重 + 追加解析

| 场景 | 后端行为 | 前端行为 |
|---|---|---|
| 第一次上传 N 张图 | `POST /api/v1/sessions` 创建新 session + 解析全部 N 张,返 `session_id` | 记录 `session_id`, 切到详情页 |
| 详情页点"添加图片" + 选择 2 张(含 1 张已识别的) | `POST /api/v1/sessions/:id/images` 走 `AppendImages`,已识别那张跳解析,新那张调 VLM,续接 seq | 显示 toast "已识别 1 张, 跳过" + "新识别 1 张 (N 行)" |
| 详情页点"添加图片" + 选择 1 张全新图 | 同上,跳过空,新图解析 | 显示 "新识别 1 张 (N 行)" |
| 用户重复点"提交识别" 但图没变 | 同上,后端判 hash 命中,全部跳解析 | 显示 "0 张新图 (已识别过)" |

### 1.2 异步策略分析

| 阶段 | 后端 | 前端 |
|---|---|---|
| 解析完成 (立即) | `analysis_status = 'pending'` → 后台 goroutine 启动 → 立即 `running` → LLM 跑完 → `done` | 立即显示单据(无 icons/summary),显示"分析中..." loading |
| 分析中轮询 | (后端在跑) | 简易 `setInterval` 1.5s 轮询 `/api/v1/sessions/:id/analysis-status`,直到 `done` |
| 分析完成 | `analysis_status = 'done'` + 写入 `alerts` 和 `summary` 字段 | 调一次 `GET /api/v1/sessions/:id` 拉完整数据(可缓存在前端),展示 icons + 总结栏 |
| 分析失败 | `analysis_status = 'failed'`,`analysis_error` 字段有原因 | 顶部红条显示 "分析失败: {analysis_error}" + 按钮 "重试" (调 `POST /api/v1/sessions/:id/analysis-retry` — 待实现,本期先 disable) |

### 1.3 总结栏 + 行内图标

- **总结栏**: `GET /api/v1/sessions/:id` 响应里 `summary` 字段 (数组),每条 = `row_id=0` 的 alert
- **行内图标**: 同一个响应里 `alerts` 字段,按 `row_id` 跟 `rows[].row_id` 关联
- **图标映射**:
  | category | 显示 | 含义 |
  |---|---|---|
  | `block` | 🔴 红色感叹号 | 限入场 (block_entry) |
  | `warn` | 🟠 橙色感叹号 | 不允许退货 (no_return) / 高库存 (high_stock) |
  | `info` | ⚪ 灰普通感叹号 | 反季 / 节假日 lead / 难消化 (后续) |
  | `highlight_dui` | 🟢 绿色"贴切"图标 (🏷️) | 堆头陈列 (has_duitou + promotion_fee 在期内) |
  | `highlight_others` | 🟢 绿色"其它"图标 (📌) | 快讯/端架 (flash_promo) |

## 二、新增端点

### 2.1 `POST /api/v1/sessions/:id/images`

**用途**: 追加图片到已有 session, 自动判重(按 sha256), 只解析新图,续接 seq。

**权限**: `session:update` (同 UpdateRow)
**限流**: 跟 CreateSession 一样, 走 `limiter.Middleware(wait)`

**请求** (multipart/form-data):
| 字段 | 必填 | 说明 |
|---|---|---|
| `files[]` 或 `files` 或 `file` | 必填 | 1 个或多个图片文件, 跟 CreateSession 一致 |

**响应** (200 OK):
```json
{
  "session_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "added_rows": [
    { "row_id": 42, "seq": 18, "image_index": 2, "raw_barcode": "...", "matched_name": "...", "qty": 5, "status": "OK", "is_new": false }
  ],
  "added_count": 1,
  "skipped_hashes": ["a1b2c3d4..."],  // 已存在的 hash 数组, 用于前端展示
  "skipped_count": 1,
  "new_hashes": ["e5f6g7h8..."],
  "new_count": 1,
  "analysis_status": "pending"  // 后台分析中
}
```

**错误**:
- `400` 没收到 file/files
- `404` session 不存在
- `500` 解析失败 (orchestrator 内部错, 但单图失败不会阻断, 见 store.AppendImages 注释)

### 2.2 `GET /api/v1/sessions/:id/analysis-status`

**用途**: 轻量轮询端点, 拉分析状态 + 计数。 比 `GET /api/v1/sessions/:id` 轻(不拉 rows)。

**权限**: `session:read`

**响应** (200 OK):
```json
{
  "session_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "analysis_status": "done",        // pending | running | done | failed
  "analysis_at": "2026-09-03T12:34:56Z",
  "analysis_error": "",
  "alert_count": 7
}
```

**前端轮询策略** (建议):
- 创建/append 后立即返回 `analysis_status='pending'`,前端开始轮询
- 1.5s 一次,直到 `done` 或 `failed`
- `done` → 调 `GET /api/v1/sessions/:id` 拉完整数据(单次)
- `failed` → 顶部红条 + 禁用"提交"按钮(等修)
- 超过 60s 没动 → 停止轮询,显示"分析较慢,稍后刷新"

### 4.3 状态轮询 Hook (伪代码)

```js
// useAnalysisStatus.js
import { useEffect, useState } from 'react';

export function useAnalysisStatus(sessionId, baseUrl) {
  const [status, setStatus] = useState('pending');
  const [error, setError] = useState('');
  const [alertCount, setAlertCount] = useState(0);

  useEffect(() => {
    if (!sessionId || status === 'done' || status === 'failed') return;

    let timer = null;
    let cancelled = false;
    let attempts = 0;
    const MAX_ATTEMPTS = 40;  // 40 * 1.5s = 60s

    const tick = async () => {
      if (cancelled) return;
      attempts++;
      try {
        const r = await fetch(`${baseUrl}/api/v1/sessions/${sessionId}/analysis-status`);
        if (!r.ok) throw new Error(`HTTP ${r.status}`);
        const d = await r.json();
        setStatus(d.analysis_status);
        setAlertCount(d.alert_count);
        setError(d.analysis_error || '');
        if (d.analysis_status === 'pending' || d.analysis_status === 'running') {
          if (attempts < MAX_ATTEMPTS) {
            timer = setTimeout(tick, 1500);
          } else {
            setError('分析较慢, 请稍后手动刷新');
          }
        }
      } catch (e) {
        setError(String(e));
      }
    };

    tick();
    return () => { cancelled = true; if (timer) clearTimeout(timer); };
  }, [sessionId]);

  return { status, error, alertCount };
}
```

// 客户端先算 hash, 提示"这张已识别过" (避免上传)
async function sha256(file) {
  const buf = await file.arrayBuffer();
  const hash = await crypto.subtle.digest('SHA-256', buf);
  return Array.from(new Uint8Array(hash)).map(b => b.toString(16).padStart(2, '0')).join('');
}
